## 项目目录规范

每个项目尽量采用：

```text
xx_project_name/
├─ README.md
└─ main.py
```

项目复杂后再逐步增加：

```text
tests/
requirements.txt
config.example.json
```

不要为了“看起来专业”一开始就堆很多空目录。
